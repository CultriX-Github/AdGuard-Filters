! CHANGELOG (v1.0.2):
! • Fixed syntax: removed non-AdGuard comment style (no /* ... */ blocks).

! • Alphabetized major domain lists for maintainability.
!
! DESIGN PRINCIPLES
! • DNS context only (no cosmetic rules, no URL paths/params).
! • Specific domains first (fast, predictable) → scoped regex patterns (carefully anchored).
! • Allow rules use $important for priority; regex allowlists omit modifiers for parser stability.
! • Aggressive/optional rules are COMMENTED out by default — enable consciously.
!
! DEBUGGING PLAYBOOK
! 1) Check AdGuard Query Log → filter “Blocked by custom filtering rules”.
! 2) If a site/app breaks: allowlist the exact hostname with: @@||broken.host.tld^$important
! 3) If breakage came from a regex family: keep the regex, add a precise @@ exception for the app/site.
! 4) TLS/SSO weirdness (random login failures): verify OCSP/CRL/PKI allow rules in Section 11.
!
! TUNING PLAYBOOK
! • Want stricter privacy? Uncomment Section 10 (AGGRESSIVE) selectively.
! • Want fewer false positives? First disable the broad tracking regex lines in Section 3.2, then re-test.
! • Handling CNAME cloaking: watch logs for first-party “analytics.*” domains and block/allow per-site.
!
! REGEX NOTES
! • All regex entries are anchored: ^ and $ match the FULL hostname.
! • TLD class uses [a-z.]{2,} to tolerate multi-label TLDs (e.g., co.uk).
! • PERFORMANCE NOTE: This list includes 31 regex patterns. On weak DNS hardware, consider disabling the broad families in Section 3.2 first.
